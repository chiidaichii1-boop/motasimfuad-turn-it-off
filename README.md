One funny line a hopeless tech support agent gives a desperate customer,
for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The line

> Have you tried turning it off and on again? If that doesn't work, try apologising to it first — mine only cooperates when it feels respected.

## How it works

`main.py` (Python 3 stdlib only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Fully
deterministic — the same bytes every run.

## Run

```sh
python3 main.py
```
